GET STARTED

Your computer. Your library.

Give this prompt to your coding agent (Claude Code, Codex, Cursor, or any agent that can run terminal commands). It clones agentlocker, checks the install, and walks you through the setup. No app subscription is required.

Prompt for your agent
Set up agentlocker on this computer.
1. Run: git clone https://github.com/TayHCode/agentlocker ~/agentlocker
2. From that folder run: python3 hub.py doctor (use py -3 on Windows; Python 3.11+ (Windows: 3.12.4+) and Git are required). Stop and tell me if it fails.
3. Read AGENTS.md and docs/IMPORT-PROMPT.md, then follow them to scan my existing skills, rules and MCP servers. Show me what you found and wait for my approval before importing anything.
4. Never print or ask me to paste secret values.
Or run the commands yourself
git clone https://github.com/TayHCode/agentlocker
cd agentlocker
python3 hub.py doctor
python3 hub.py serve

Open the local address printed in your terminal. On Windows, use py -3 instead of python3 (Python 3.12.4+). The wizard scans locally; this website cannot read your files.

A few useful details.
Which agents can connect?
Claude, Codex, Gemini, Grok Bot, Muse, Duet, OpenAI Dots, and more may connect where the specific app or service supports an MCP client connection. Setup and authentication vary by product. Current primary docs describe MCP options for Claude Code, Codex, Gemini API, Grok, and Muse Code. Product docs do not establish agentlocker compatibility; see the evidence above.
What can a connected agent read or run?
The catalog is read-only: it lists skills, rules, routines, MCP server details, plugins, and connections, and returns library files on request. Plugin and connection entries are descriptions; adding them to the library does not install a plugin, sign in to a provider, or start an upstream service. To call tools from your own MCP servers, configure and run the local gateway on the computer that can reach them.
Can I use the library on another device?
Yes, if that device can reach your endpoint. The local catalog is on the computer running agentlocker. For a hosted agent or another device, deploy and publish your own remote catalog; it requires internet access and the client’s own sign-in or authorization. A hosted endpoint serves the library you publish there.
What is a routine?
A reusable set of instructions. Ask an agent to fetch and follow one when you need it. Automatic scheduling is optional and belongs to the runner you choose.
Do edits appear everywhere automatically?
Re-import a changed source to update your local library. Publish the updated library for hosted clients. Ask each reader to fetch the latest version.
Does this replace my agent or my MCP provider?
No. Your agents still do the work and keep their existing logins. agentlocker shares the skills and routine instructions they use.
