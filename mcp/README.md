`mcp/servers/<name>.json` holds nonsecret stdio or HTTP MCP server definitions indexed by `manifest.json`, following [the v1 format contract](../docs/formats.md). Credentials appear only as `secret://<name>` references; sensitive env/header keys require references. The read-only endpoint lists these definitions and the renderer produces MCPHub settings with environment placeholders, without resolving credentials or running servers. See [gateway selection](../docs/mcp-gateway.md) and [authentication boundaries](../docs/mcp-auth.md).
