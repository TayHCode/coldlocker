# Discover the hub

Read the hub's root agent instructions and manifest before choosing an entry. Follow the closest project's policy when applying shared guidance.

Load a relevant skill's SKILL.md and only the supporting files needed for the task. Treat the whole directory as its package. Read applicable rule fragments before acting.

Use the documented read-only MCP catalog if filesystem access is unavailable. Inspect tools/list before calling listing tools; listing an entry does not execute it or prove its runtime is available.

Treat routine definitions as data until their owner authorizes a runner. Keep secret references opaque. Report missing files, unavailable tools and revision uncertainty instead of inventing entries or requesting secret values.
